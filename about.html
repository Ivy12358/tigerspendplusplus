About TigerSpend++

What is TigerSpend++?

TigerSpend++ is a web app I built for RIT students to help keep track of dining dollar spending and managing a meal plan. The app was originally just a large personal spreadsheet I maintained to track my own spending, but eventually I decided to turn it into a site usable by all Tigers.

How is TigerSpend++ Built?

TigerSpend++ is built using plain HTML, CSS, and JavaScript. It uses the Apache ECharts library for data visualization, and assets from makeaero.com for button styles.

The background image is a render made in Blender by me!

Tigerspend++ is a static site, meaning all the data processing is done in your browser. No dining information is sent to external servers, and all files are processed locally on your device.

The code for TigerSpend++ is available on GitHub at github.com/Ivy12358/tigerspendplusplus, while the site itself is hosted using Cloudflare Pages

What is planned for TigerSpend++?

TigerSpend++ is constantly getting new updates, in the future I hope to add these features:

  • Spending per day graph
  • Most visited vending machines
  • Spending breakdown, including how much to spend per day until the end of the semester
  • Shareable "TigerSpend++ Wrapped" esque reports
  • Mobile support (this might take a while)
  • Fixing all the typos i'm sure are in here
  • Account connection to automatically pull in dining data (I actually had this in the last version, but RIT broke the method I was using)
